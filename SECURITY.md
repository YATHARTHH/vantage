## Reporting a Vulnerability

Security is paramount for telemetry and observability infrastructure. If you discover a potential security vulnerability in Vantage, please **do not** open a public issue on GitHub.

Instead, please report the vulnerability directly to our team:
- **Email**: `security@vantage-observability.io` (or repository maintainer)
- **Response Time**: You will receive an acknowledgment within 24 hours.

Please include the following details in your report:
- Type of vulnerability (e.g. prompt injection, unauthorized API access, sensitive data leak)
- Step-by-step instructions or proof-of-concept script to reproduce the issue
- Impact assessment and suggested remediation

We appreciate your assistance in keeping Vantage safe for everyone!
